LCP: main content

How long until the biggest thing on screen appears. Google's "good" line is 2.5 seconds.

TBT: tap lag

How long scripts block the page from responding. Under 200 milliseconds feels snappy.

CLS: jumpiness

How much the layout shifts while loading. Under 0.1 means fewer accidental taps.

Website speed test questions

Is this website speed test free?

Yes. It is completely free and needs no sign-up. It uses Google's free PageSpeed Insights service.

What is a good website speed score?

On Google Lighthouse, 90 to 100 is good, 50 to 89 needs improvement, and below 50 is poor. Mobile scores are usually lower than desktop.

Why is my mobile score lower than desktop?

The mobile test simulates a mid-range phone on a slower network, which exposes heavy images, scripts and fonts that a fast desktop hides.

How do I make my website faster?

Compress and resize images, remove unused scripts and plugins, load fonts efficiently, and use lean, custom code. That is how we build every site.
